Coordinator cancellation includes the atomic power guard: a bounded operation already running can return and persist progress, while the next unit is held. Failed writes hold control and honor retry backoff. Observation leaves recovery bytes unchanged.

The characterized policy starts a full configured recovery delay after reliable no-game evidence. Manual holds survive. Coexistence remains inactive while inventory refreshes and can continue only for the verified original live process instances. Failed/unknown detection revokes it. Actual sleep/wake and live provider restart behavior remain untested.
